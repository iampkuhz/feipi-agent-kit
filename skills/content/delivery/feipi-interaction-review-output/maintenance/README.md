# 维护入口

能力域为 interaction，主动作 review，对象 output；主要产物是交互审查意见与可用汇报，归 authoring。它与文字精炼同级独立，不承担渠道接入、通知服务或产品验收。

## 职责与消费者

- `SKILL.md`：输入、触发、审查修订编排和交付边界；消费者是当前任务 Agent。
- `references/delivery-review.md`：审查判断与复审标准。
- `references/channels.md`：按实际渠道能力处理展示、访问和操作。
- `agents/openai.yaml` 与仓库 registry：版本、发现与定向安装；项目 `AGENTS.md` 决定本地汇报的调用时机，不复制标准正文。
- `tests/run.sh`：隔离目录中的真实定向安装，验证运行资源完整、开发目录排除及其他入口保留。不是语义效果评估。
- `evals/cases.json`：真实 Agent 行为用例和独立判据；运行产物留在仓库忽略的唯一临时目录，不进入 Skill。

修改触发或交付行为时，同步元数据、受影响案例和项目规则消费者。新版本先结构与安装检查，再审阅真实 Agent 的问题定位、修订和复审效果；手机实显与远程接收有独立证据才记通过。运行规则不依赖本目录、测试或评估资料。
