# 术语与边界

| 名称 | 含义 |
| --- | --- |
| 交付物 output | Agent 准备给用户的进度、结论、报告、产物入口或决策说明；不是任务内部全部日志。 |
| 交互审查 | 判断指定交付在目标渠道里是否可读、可访问和可操作，并指出可执行修正。 |
| 当前版本 | 本次即将交付的文案及其对应事实、文件与动作；旧稿审查不能代表新稿。 |
| 调用 Agent | 负责原任务并消费审查意见的执行者；也可以在同一上下文自检，不要求独立子 Agent。 |
| 渠道能力 | 当前连接实际可用的展示、附件、链接、按钮或消息更新能力；平台理论能力不能替代核实。 |
| 文字精炼 | 内容语义、解释关系与自然表达的独立能力；不是本 Skill 的必装依赖。 |
