# 交互协议

不把“一页一确认”作为全局规则。材料完整且没有关键分歧时，直接生成和 QA。

## 需要询问

- 核心结论不明确；
- 两个叙事方向都合理并会改变认知任务；
- 必须删除重要内容；
- 必须拆页；
- 选择会改变业务含义。

一次只呈现少量真正决策点，说明推荐项和影响。不要重新询问用户已经明确的要求。

## 不需要询问

- 字体、字号、颜色、间距、圆角、线宽；
- 已登记组件的固定视觉属性；
- 合同允许的 region 和确定性几何；
- 普通 QA 修复中不改变业务含义的文本去重或合同内 size/layout 切换。

Page Contract 可以作为内部规划。只有上面的关键分歧存在时，才把相关部分转成用户可见决策卡片。
