# 信息充足性

优先从用户材料中推导，不把未填写的格式字段都变成问题。

生成页面至少需要：可识别的主题、可提炼的核心结论、支撑该结论的事实，以及足以判断认知任务的关系。缺少次要标签、配色选择或现成 layout 名称不构成阻塞。

只有以下缺口需要询问：

- 无法确定核心结论且不同解释会改变业务含义；
- 架构/流程/对比缺少关键关系，任何补全都需要编造事实；
- 关键数字或对象互相矛盾；
- 页面必须删除重要内容或拆页。

可以在不改变含义的前提下自行完成：短标题改写、同义内容合并、分组、来源移到脚注、从登记 Layout/Component 中选择表达。

提问时只指出会阻塞当前认知任务的缺口，不要求用户描述视觉风格，也不重新询问已明确要求。
