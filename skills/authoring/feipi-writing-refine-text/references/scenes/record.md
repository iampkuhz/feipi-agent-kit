# 纪要与复盘

目标是保留能追溯的事实、决定与原因。讨论过程里，影响责任、分歧或决策的历史本身就是有效信息。

- 纪要区分事实、提议、已批准决定、未决分歧和行动；发言人的建议不能改成团队决定。
- 复盘保留事件时间线、影响、发现与处理过程、证据和未验证假设。合并复述时不合并不同阶段的状态。
- 决策记录保留必要方案差异及拒绝或采纳理由，不把所有备选讨论视为废话。
- 保留责任人和日期；未指定责任人或截止时间就不要补。材料冲突时保留归属并指出待确认项。
- 用户要逐字纪要或保留问答时按其要求处理，不能擅自重构为当前状态报告。

验收：读者能区分发生了什么、决定了什么、为什么，以及什么尚未确认。去掉附和与重复发言，但不能制造共识或抹去责任。
