# 优化正文

## LexiFlow 交付状态

观看链路、词库存储、本机部署和工程工作流已有实现，真实观看体验与正式发行仍有待验证。

### 已有实现

- 观看链路只消费已发布资料。英文不等待后端、不调用模型；字幕切换、版本冲突和依赖故障时安全降级。本机抑制偏好不上传。
- 词库存储采用精简 entry、form 与 dataset 模型，对外词条 ID 使用十进制字符串，协议为 `caption-hints.v2`。结构变化仍须显式重建重导，源码更新不等于运行资料已更新。
- M 芯片 macOS 已有 Podman 本机安装和更新入口，包含引擎与资源归属、锁、资料身份及失败恢复检查。操作命令见[用户指南](../../../user/podman-macos.md)。
- 工程工作流已实现按风险开展开发自检、独立验收分层、同事务检查复用及证据查询优化。

### 检查结论的适用范围

最近完成的独立开发检查为 25 项 PASS、22 次物理执行，757 项冻结输入无漂移，墙钟耗时 21 分 37 秒。该结果只适用于当时的累计混合变更；此后配置精简又修改了输入，最终结论须以本轮冻结报告为准，不能沿用先前 PASS。Formal、完整 Repository baseline 和正式发行未在本轮验收，开发 PASS 也不代表用户机器验收完成。

### 待完成事项
