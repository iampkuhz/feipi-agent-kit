# 优化正文

## LexiFlow 文档整理进展

文档目录、阅读入口及关联引用已完成整理。当前结构以 [docs/README](../../../README.md) 为唯一工程入口：system 解释系统主题，scenarios 按真实任务组织操作，reference 提供查阅资料；roadmap 与 user 保留独立职责。原三个视角目录已合并删除，Harness、Catalog、风险路径和引用者已同步，门禁覆盖未降低。

### 阅读与维护方式

| 调整 | 当前做法 |
| --- | --- |
| 按一个生命周期组织工作 | 合并通用范围与验收要求；区分实现自检和交付证明；维护阶段包括文档，不另设反馈阶段。 |
| 按任务设置操作页 | 修改导入、执行门禁、优化门禁分别成页；优化页引用执行页，不复制运行子图。 |
| 先解释目的，再提供实现清单 | 总览区分三体系，操作入口按目标选择，逐项检查库存放在 Reference；用途、场景、范围与入口各司其职，不混为同一层次。 |
| 明确规则与操作的存放位置 | 人类文档规则维护在 Harness Markdown；docs 保留导航和维护操作，不另存原则清单。 |
| 为同一主题维护一份正文 | 合并来源／字幕内容以及总入口和本机操作索引；决策理由随系统主题维护，相关页面通过引用关联。 |
| 规范链接与加粗格式 | 主导航使用相对文件链接，结束加粗标记与后文分隔。 |

### 与工程实现的同步范围

当前工程机制包括：开发只保留唯一 diff 报告与精确诊断；Registry 合并 canonical Check/scene 和 CI policy；Git 提醒入口已删除；环境与来源身份保持真实认证；Codex 每 Task 只引用不可变父合同；Gate 使用唯一活动 namespace 和最新 schema。

用户已确认没有需要续用的外部旧运行或收据，因此 Qoder 委派和旧事实消费说明已退役，仅保留手工客户端 Stop 与权限 profile。

### 验证结果与待确认项

文档内容与文件地图已完成独立只读复核。最近完成的静态检查覆盖 58 个文件、25 张内嵌图，相对链接与片段已核对。图源有校验和预览证据：六张受影响图经实际校验、渲染和查看后原样复制，未改图保留字节；修订的共用检查图重新校验、渲染与视觉核对后复制正文；配置精简涉及的两张图也重新渲染、视觉核对后复制正文。

静态检查只证明链接与结构，不能据此认定独立验收、Formal 或真实发行通过。最终检查须以统一冻结后的报告为准；源码集成和独立验收仍需后续真实证据。本轮未重新在 IDE 内逐个点击链接，阅读效果仍待用户确认。
