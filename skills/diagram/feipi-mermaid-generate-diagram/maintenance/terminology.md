# 术语与边界

- brief：声明图意、节点、关系和布局的输入，决定语义验收预期。
- profile：六种受支持业务图型的约束；不是新的 Mermaid 语法。
- 本地浏览器：显式指定或自动发现的可执行程序，与固定 npm 包分别准备。
- 共享缓存：可重建的 npm 运行依赖，按锁文件、系统和 Node ABI 隔离，不进入技能副本或 Git。
- 预检：一次短生命周期浏览器启动，不消耗图的正式渲染次数。
- `review_required`：技术检查通过但尚未人工看图，不能表述为完成。
- 图包：源码、SVG、PNG、说明和绑定输入/工件摘要的验收报告；复用需重新检查合同和摘要。
