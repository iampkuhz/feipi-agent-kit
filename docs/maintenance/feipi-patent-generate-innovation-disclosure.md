## 2026-08-09｜v4 内容与图示治理

| 用户问题 | 优化摘要 |
|---|---|
| 顶层拆分失真 | 先建边界矩阵；顶层只保留业务域、独立系统和物理端点。 |
| 图面拥挤、文字重叠 | 限制节点、边和连接度；SVG 视觉复核绑定 hash。 |
| 流程标签重复且过长 | 主流程统一 `S` 编号和动作短语，参数与异常移至图下。 |
| 关键词随意、区分度低 | 固定 5–8 个并按技术对象、核心机制、关键约束互斥分类。 |
| 创新点停留在普通模块拆分 | 先写核心发明主张；`I` 项补齐机制、约束、差异和落点。 |
| 技术效果缺少因果关系 | `I/T` 双射；效果写明原问题、机制、结果和验证状态。 |
| 高概括内容缺少语义门禁 | 增加泛化替换测试和因果删除测试，待复核则不判成功。 |
| 来源事实、发明扩展和实现混杂 | 建立三类来源台账、术语泛化和缩写白名单。 |
| 竞品与相似方案缺少证据 | 改为 1–3 条完整证据或诚实标记“待检索”。 |
| 校验只保格式、不保内容 | 升级为结构、内容、图包同源、hash 与人工复核联合门禁。 |
